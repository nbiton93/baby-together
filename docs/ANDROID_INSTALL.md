# התקנת גרסת הניסיון לאנדרואיד

נוצר קובץ התקנה חתום: `baby-together-0.1.0-local-preview.apk`.

זו גרסת מעקב מקומית. היא פועלת ללא ChatGPT ושומרת את הרישומים בטלפון. חיבור Google ושיתוף הנתונים בין הטלפונים עדיין כבויים עד להשלמת [הגדרת Google](GOOGLE_BROWSER_SETUP.md) ובניית עדכון.

## התקנה

1. הורד את קובץ ה־APK שנמסר לך לטלפון Android עם Android 8 ומעלה.
2. פתח אותו דרך ההורדות. אם Android מבקש הרשאת התקנה למקור שממנו פתחת אותו, אשר את ההתקנה של הקובץ הזה.
3. פתח את Baby Together, מלא את שם הכותב ואת פרטי התינוקת, ונסה להוסיף ולערוך רישום.
4. סגור ופתח את האפליקציה וודא שהרישום נשמר. לפני שמירת מידע שחשוב לך, בדוק גם ייצוא גיבוי דרך ההגדרות.

לעדכון יש להתקין את הגרסה החדשה מעל הקיימת, באותו מפתח חתימה. אין להסיר את האפליקציה כדי לעדכן: הסרה מוחקת את הנתונים המקומיים. שחזור מקובץ עדיין אינו זמין בממשק.
