# Baby Together

אפליקציית מעקב לתינוקות בעברית, לאנדרואיד ולאייפון. אין שימוש בחשבון ChatGPT, ב־OpenAI API או בשרת של ChatGPT בזמן השימוש באפליקציה.

**מצב נוכחי: קוד פיתוח, לא קובץ התקנה.** נכתבו הפרויקטים לשתי הפלטפורמות. בדיקות הלוגיקה ב־Node עברו. קומפילציה למכשירים, Google OAuth וסנכרון מול שני חשבונות אמיתיים עדיין לא נבדקו. אין APK או IPA מאומתים בארכיון הזה.

## מה נכתב

- האכלה מבקבוק או הנקה, חיתולים, טיימר שינה ורישום שינה ידני, שאיבה, משקל והערות.
- יומן לפי יום, סיכום שבועי, פרטי התינוקת ושמות ההורים.
- שמירה אטומית במכשיר לפני ניסיון סנכרון, כולל עבודה ללא אינטרנט.
- עריכה, מחיקה עם אפשרות שחזור ושמירת גרסאות במקרה של עריכות מקבילות.
- קוד לחיבור Google Drive עם `drive.file` בלבד ובורר קבצים של Google.
- כל מכשיר כותב לקובץ נפרד; בן או בת הזוג מקבלים הרשאת קריאה. פעולות מכל המכשירים מתמזגות ליומן אחד. שניכם יכולים להוסיף ולערוך את הרשומות באפליקציה.
- ייצוא גיבוי JSON דרך חלון השמירה או השיתוף של הטלפון. שחזור גיבוי מקובץ עדיין אינו זמין בממשק.

## מבנה

- `shared/`: הממשק, אימות הנתונים, מנגנון המיזוג וקוד הסנכרון. קבצים מקומיים הכלולים בהתקנה, לא אתר שמתארח ברשת.
- `android/`: מעטפת Android ב־Java עם WebView מקומי ו־Google Identity Services.
- `ios/`: מעטפת iPhone ב־Swift עם WKWebView מקומי, OAuth עם PKCE ו־Keychain.
- `tests/`: בדיקות ללא תלות בספריות חיצוניות.
- `.github/workflows/build.yml`: הגדרת בנייה ל־GitHub Actions. טרם הופעלה.

## בדיקות

נדרש Node 20 ומעלה, ללא `npm install`:

```sh
node scripts/check.cjs
TZ=UTC node --test tests/*.test.cjs
```

## יצירת APK

נדרשים JDK 17, Gradle 8.13, Android SDK 36 וחיבור להורדת תלויות Google/Maven. אין צורך ב־Node או npm לבנייה לאנדרואיד.

```sh
gradle -p android assembleRelease lintRelease
```

התוצר יהיה APK לא חתום. ב־GitHub Actions התוצר מופיע תחת `baby-together-android-unsigned`, לצד כלי החתימה והסקריפט. יש לחתום באמצעות `scripts/sign-android.sh` ומפתח פרטי קבוע. הסקריפט אינו שולח את המפתח לשום שירות. APK לא חתום אינו ניתן להתקנה.

עד לסיום Google Cloud יש להשאיר `GOOGLE_ANDROID_CONFIGURED=false`. מצב זה מאפשר מעקב מקומי ומציג שחיבור Google אינו זמין.

## iPhone

נדרשים macOS, Xcode ו־XcodeGen:

```sh
xcodegen generate --spec ios/project.yml
open ios/BabyTogether.xcodeproj
```

יש לבחור צוות חתימה ופרופיל מתאים ב־Xcode. הפצה דרך TestFlight דורשת את חשבון המפתחים וההגדרות של Apple. תוצר הסימולטור מ־Actions אינו קובץ התקנה לאייפון. לא נוצרו אישורי Apple ולא בוצעה הרשמה בתשלום.
